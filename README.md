# checklist-execution-system-ui

Angular 19 SPA frontend for the Checklist Execution System.

## Prerequisites

- Node.js 22 (use `nvm use` to switch automatically)
- npm 10+
- Angular CLI 19: `npm install -g @angular/cli@19`

## Tech Stack

- **Framework**: Angular 19 (standalone components, signals)
- **Styling**: Tailwind CSS v3 + Angular Material
- **Markdown**: ngx-markdown with Prism.js (Phase 7)
- **Drag and drop**: Angular CDK (Phase 7)
- **Testing**: Karma + Jasmine

## Local Development

```bash
npm install
npm start       # http://localhost:4200
npm test        # run tests
npm run build   # production build
```
